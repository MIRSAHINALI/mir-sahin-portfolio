# Content editor

Use `/admin/` to add or update projects. Use `/admin/content/` to edit profile details, experience, education, skills, certifications, social links, gallery content, and the résumé.

Upload images or a PDF résumé, then select Save changes. Saved content is stored in Neon and uploads in Vercel Blob. Content updates do not require a deployment.

See README.md for setup, authentication, deployment, and maintenance instructions.
